WHAT I CAN DO FOR YOU

Figma design to working website.

Have a design ready in Figma? I turn it into a clean, responsive website that looks like the design and works on phones, tablets and desktops.

Send me your design ↗
  1. 01

    Review the design

    I go through your Figma file: layout, colours, fonts, spacing and the different screen sizes.

  2. 02

    Build with HTML & CSS

    I structure the page with semantic HTML and match the design closely using Flexbox and Grid.

  3. 03

    Make it responsive

    The layout adapts smoothly across mobile, tablet and desktop, and I add JavaScript where the design needs interaction.

  4. 04

    Test and deploy

    I compare the result to the design, fix differences, then publish it as a live website you can share.
